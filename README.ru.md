# Анализ и синтез интерференционных покрытий

[English](README.md) | [Русский](README.ru.md)

**Опубликованная документация:** https://ekatmoz88-alt.github.io/interference-coatings-analysis-synthesis/

Научно-инженерный проект по анализу, проектированию и синтезу многослойных оптических интерференционных покрытий.

## Обзор

Методика рассчитывает спектральные характеристики тонкоплёночных оптических систем и подбирает многослойные структуры под заданные характеристики отражения, пропускания и поглощения. Математическая модель описывает распространение электромагнитной волны в однородных изотропных слоях с использованием комплексных показателей преломления и матричного метода.

## Основные направления

- Расчёт спектральных коэффициентов отражения (R), пропускания (T) и поглощения (A).
- Анализ многослойных покрытий при нормальном и наклонном падении.
- S-, P-, круговая и произвольная линейная поляризация.
- Материалы с дисперсией показателя преломления и коэффициента поглощения.
- Синтез и оптимизация по целевому спектру.
- Оценка чувствительности к изменению параметров слоёв.

## Методы оптимизации

Описаны случайный поиск с переменным шагом и метод направлений Пауэлла. Их сочетание рассматривается как методика поиска структуры, приближающей расчётный спектр к заданному.

## Историческая реализация и статус

Исходная программа описана как приложение на Object Pascal / Borland Delphi для Windows. Репозиторий сейчас находится на стадии документации; современная реализация, полный исходный код и воспроизводимые тестовые наборы не заявляются.
